調音小叮嚀

  • 指針在中間、顯示綠色（±3 cents 內）才算調準。比賽前建議每條弦都調到綠色。
  • 先調 A 弦，再調 D、G、E。用微調器小幅轉動，大幅偏差才轉弦軸。
  • 點下方弦名可以播放標準音，用耳朵比對。
  • 直笛無法調弦：吹嘴往外拔一點音會變低、推緊會變高；吹太用力也會偏高。
  • 合唱：選「合唱起音器」，按「主和弦」聽調性，再按自己聲部的起音，唱出來看指針準不準。

加入新樂譜

  1. 紙本或照片：把樂譜拍照（或 PDF）上傳給 Claude，說「幫我轉成練琴小幫手格式」，把拿到的文字貼到下面。
  2. MusicXML 檔（最快、最準）：MuseScore.com（公版曲免費，有版權的曲子需購買授權）、IMSLP 部分樂譜附的 MusicXML、OpenScore 公版樂譜、合唱曲可找 CPDL 合唱公版樂譜庫，下載後直接選檔或拖曳進來。
  3. 只有 PDF：用免費的 MuseScore 4「匯入 PDF」或 Audiveris 轉成 MusicXML，再匯入。轉換常有小錯，匯入後請對照原譜。
  4. 加入後到「練習」頁確認音符和原譜一致，再開始練。

也可以把好幾個 MusicXML 檔一次拖曳到這一頁。

練琴小幫手格式說明 
{
  "title": "曲名", "composer": "作曲者",
  "instrument": "violin",   // violin 小提琴、recorder-s 高音直笛、recorder-a 中音直笛
  "tempo": 80,              // 每分鐘幾個四分音符
  "time": "3/4",            // 拍號
  "key": "G",               // 調號：C G D A E Bb Eb…，小調加 m，如 "Em"
  "measures": [ "D4:q G4:8 A4 B4:q", "C5:h. ~", "C5:q R:q D5" ]
}

音名＋八度（C4 是中央 C），寫實際要演奏的音：F#5、Bb4、Cn5（還原）。冒號後是時值：w 全、h 二分、q 四分、8、16、32；加 . 是附點、t 是三連音、~ 接連結線。R 是休止符。同一小節內省略時值會沿用前一個，每小節開頭預設四分音符。

設定

麥克風與評分標準

麥克風

建議使用夾式麥克風，夾在琴身旁（小提琴）或衣領（直笛），距離音源 15–30 公分。系統已關閉降噪與自動音量，保留原始音色。

延遲校正

藍牙耳機、外接音效卡都會讓聲音晚一點到。校正後節奏判斷才準：按下後會先響 2 聲預備，接著 8 聲，請跟著拍手或用弓拉短音。

戴耳機練習效果最好：節拍器和示範旋律不會被麥克風收進去。

音準基準

Hz

台灣學生音樂比賽多與鋼琴伴奏合奏，常見 440 或 442 Hz；請依比賽伴奏鋼琴或老師指示設定。

純律五度、八度沒有拍音，最好聽；純律大三度比鋼琴窄約 14 cents。

容許誤差

綠燈＝在綠色範圍內；黃燈＝超出綠色但在黃色範圍內；超過黃色範圍就是紅燈。

評分校正（給老師）

老師可以在練習報告按「老師覆核燈號」，依自己的聽感修正小節燈號。累積 10 個以上，小幫手會算出最符合老師標準的容許度。

音準基準與比賽

表情音準：導音（例如 D 大調的 C♯）往主音靠近、略高 12 cents 以內不扣分，比較接近弦樂老師的要求。請依老師的指導選擇。
